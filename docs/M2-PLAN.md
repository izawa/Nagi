# M2 雨とランダムの計画

版: 0.1(2026-11-20)/状態: 作者の判断を反映。段階 A の前

M2 では、画面の取り込み、権限の案内、ランダムモード、雨を作り、v0.2 にする(SPEC 7 章)。完了の条件は 2 つある。SPEC 4.2 の受け入れ基準を作者が目で見て通すことと、雨を足すときにコアに手を入れずに済んだことである。この文書は、作る順序、確かめ方、作者に見てもらう区切りを決める。

計画は Claude と Codex がそれぞれ独立に作り、突き合わせて 1 つにした。アドバイザーにも相談した。どちらの案から何を採ったかは 7 章に書く。

## 1. 前提

### 1.1 開発機

M1 と同じ。Mac mini(M4 Pro)、macOS 27.2.1、Studio Display(5K、60 Hz、EDR の余裕 2)1 台。

### 1.2 M1 から引き継ぐもの

- コアは `.glass` の層と `.backdrop` の背景テクスチャをすでに扱える。`FrameRenderer` は、取り込んだ画面に下の層(木漏れ日)を WindowServer と同じ式で合成してから、`.backdrop` のエフェクトに渡す。M1 では取り込みの代わりに試験用の画像を渡して確かめた(M1-PLAN 1.3)
- `nagi-render` の `--background` は、そのまま `.backdrop` の背景になる。雨の静止画と連番は、取り込みなしで描ける
- `Effect` は、フレームに 1 回の `update` とディスプレイごとの `render` に分かれている。雨の粒の計算は `update`、描画は `render` に置ける
- 性能の余裕は小さい。木漏れ日だけで、1 フレームの GPU の時間は 5 秒ごとの平均で 8.2〜14.3 ms、最大 16.8 ms(M1-LOG の段階 6)

### 1.3 作者の判断(2026-11-20)

- 雨の既定はオフ。画面収録の許可が要るので、許可した人だけの追加エフェクトとする(SPEC 5 章)
- ランダムモードは M2 に含める(SPEC 2.3)
- 深まりには上限を設けない。雨は 2 分で本降りになって飽和するので、上限がなくても成り立つ

## 2. 作る順序と作者の区切り

コアを先に仕上げて固め、雨はそのあとでパッケージとして足す。雨を足す差分が、雨のパッケージ、アプリのパッケージの依存、エフェクトの一覧(`EffectCatalog`。アプリと `nagi-render` が共有する)の登録だけで済み、NagiCore と NagiKit に変更がないことで、M2 の完了の条件を示す。

| 段階 | 作るもの | 確かめ方 | 作者の区切り |
|---|---|---|---|
| A 取り込みと選び方 | 画面の取り込みのサービス、許可の状態と案内、設定の移行、ランダムモード、天気のヒントの求め方。動作は試験用の `.glass`/`.backdrop` のエフェクトで確かめる | 単体試験(遅れて届いたフレーム、ディスプレイの抜き差し、自分の除外、設定の移行、30 分の境目を、時計と乱数を差し替えて)。負荷を測る(3 章)。測り終えたらコアを固める | **E 取り込みと許可**(約 15 分)。許可する、拒否する、紫のインジケータから止める、取り消して「あとで行う」、起動し直す。画面共有の 2 つの設定と、遅れが見えないかも見る |
| B 粒の見た目 | 雨のパッケージと、`EffectCatalog` への登録(登録するまで `nagi-render rain` は動かない)。止まった粒の屈折(近接レンズ)、縁の暗い輪、フレネル反射、太陽の向きのハイライト、わずかな色分散、粒の下の影と集光。木漏れ日ごと屈折する | `nagi-render rain` と `komorebi,rain` の静止画を、目盛りの入った画像と読書の背景(ライト・ダーク)の上で見る。粒の中の文字が後ろの文字と対応して歪むこと、乾いた画素が変わらないこと、実解像度で縁が鋭いこと | **F 粒の見た目**(約 10 分)。実寸で 20 秒ほど読んでから、粒の大きさ、拡大の強さ、光り方を決める |
| C 動き | 粒が着き、合体して育ち、滑り落ちて小粒を残し、途中の粒を吸って速くなる。深まりに合わせて増え(20 秒までまばら、20 秒から育って流れ、2 分で本降り)、退場で蒸発するように縮む | 単体試験(質量の保存、覆う面積、同じ種で同じ結果、入力から 0.8 秒以内に消えること)。最悪の場面の連番で点滅を数える(`Tools/flicker.py --step 1`、1 秒に 3 回まで) | **G 動きと M2 の確認**(約 15 分)。10 分の通し(合体、残る小粒、本降り)と蒸発を見て、SPEC 4.2 の 6 項目を確かめる |

## 3. 性能の予算

いちばんきつい制約なので、雨の描き方を決める前に段階 A で測る。

- 測るもの: 取り込みだけ、取り込みと木漏れ日、それに背景を合成するパスを足したもの。5K、凪の間(M1 と同じ測り方)
- M0 の S4 の「取り込みで GPU の利用率が 20〜30 ポイント増」は、点滅と目印を出したままの値だった。凪の間の画面はほぼ静止していて、自分の層は取り込みから除くので、その条件で測り直す
- 取り込みの頻度は 60 Hz から始め、30 Hz と比べる。30 Hz で動く文字の上の遅れが見えるかは、区切り E で作者が見る
- 雨の描き方は、この数字で選ぶ。候補は 2 つある。全解像度の高さ場に粒を描いて全画面のパスで屈折させる形と、画面をタイルに分けて粒のあるタイルだけを塗る形である
- 合格の線: 木漏れ日と雨を両方オンにして、暖まったあとの 1 フレームの GPU の時間の 95 % 点が 16.7 ms 以下、60 Hz を保つこと、活動中は取り込みも描画もしないこと
- 超えたときの扱い(雨のあいだは 30 fps にする、など)は、数字を見てから作者が決める

## 4. コアで作るもの

### 4.1 取り込みのサービス(SPEC 3.9)

- NagiCore に置き、ディスプレイごとに 1 本の `SCStream` を持つ。凪に入るときに、動いているエフェクトに `.backdrop` を求めるものがあり、許可があれば始める。退場に入ったら新しいフレームを受け取るのをやめ、蒸発のあいだだけ最後のフレームを保つ
- 凪に入るたびに `SCShareableContent` を `onScreenWindowsOnly: false` で取り直し、自分のアプリを丸ごと除く。除けなければ、その背景は無いものとする(自分を屈折させないため)。カーソルと音は取り込まない
- 画素は符号化した Display P3 の BGRA で受け、色の見本で確かめる。最新の 1 枚だけを残し、IOSurface を `CVMetalTextureCache` でコピーせずにテクスチャにする。使う Metal のコマンドが終わるまで、フレームとテクスチャを保つ。描画は取り込みを待たない
- 開始に番号を付け、止めたあとに遅れて届いたフレームで取り込みが生き返らないようにする。ディスプレイの抜き差しと解像度の変更で、ストリームを作り直す
- ロック、スリープ、抑止、番犬による退場、許可の喪失で取り込みをやめ、保っていたフレームを捨てる
- −3801(許可なし)は許可を失ったものとして扱う。−3817(利用者がインジケータから止めた)は、その凪の間は始め直さない
- 粒をデスクトップ全体に配るには、ディスプレイの配置が要る。今の `update` は `FrameState` しか受け取らず、ディスプレイの範囲は `render` で初めて分かる。`update` にデスクトップのディスプレイの配置を渡す方法を段階 A で決め、固める前に入れる(1 枚だけの静止画を描くときも同じ)
- 背景がまだ届いていないあいだ、`.backdrop` のエフェクトには背景が渡らず、雨は何も描かない。雨は最初のフレームが届いた時点で現れ、コアに雨のための分岐は要らない
- 取り込んだ画素は GPU の外に出さない。ディスクにも書かず、ログにも出さない(SPEC 5 章)

### 4.2 エフェクトの選び方(SPEC 2.3)

- 選択モード(今の形): オンにした、動かせるエフェクトを層の順にすべて重ねる
- ランダムモード: 凪に入る時点で、オンにしていて、いま動かせる(許可がある)エフェクトから 1 つを選ぶ。選んでから 30 分のあいだは同じものを使う。凪の最中には変えない。選んだものが動かせなくなったら(許可を失ったなど)、その凪では引き、次に入るときに選び直す
- 動かせないエフェクトは、選択肢に出したまま無効の表示にし、理由を添える(SPEC 2.3)。メニューの 1 行だけでは足りない
- 取り込みが要るか、メニューの 1 行、天気のヒント(雨は曇り寄り)は、動いているエフェクトから求める。今は天気のヒントを起動時に合計しているので、選び方の経路を 1 つにまとめる

### 4.3 設定と許可(SPEC 2.5、5 章)

- 設定の移行: 今の設定は「オンにしたエフェクトの一覧が無ければ全部オン」と読み、メニューでどれかを切り替えると、無い一覧を全部の ID に広げてから書く。このままでは、雨を足した時点で雨がオンになるか、木漏れ日を切っただけで雨がオンになる。一覧の無い設定は M1 にあったエフェクト(木漏れ日)だけがオンの一覧として読み、切り替えもその一覧から始める。試験を足す。雨をオンにする操作と、許可を求める操作は分ける(オンにしたあと、許可がなければ 4.3 の流れで求める)
- 許可の状態は、まだ聞いていない、返事待ち、許可、拒否・取り消し、の 4 つ。許可を求めたすぐあとの返事は当てにならないので、アプリが前に出てきたときに確かめ直し、要れば起動し直しを案内する
- 雨を最初にオンにするとき、取り込んだ画面を Mac の中の GPU でだけ使うことを説明してから、許可を 1 回求める。2 回目からは、システム設定の「画面収録とシステムオーディオ録音」の一覧を開く
- 設定ウィンドウに「権限」のタブを足す。紫のインジケータ、初回の確認、月に 1 回ほどの再確認があることも書く
- 許可がないとき、メニューに理由の 1 行を出す。許可はコアの関心事なので、雨の `note` ではなくコアが出す
- 設定のプレビューとギャラリーは見本の画像を背景にする。ギャラリーにエフェクトを選ぶ欄を足し、深まりの上限(今は 60 秒)を本降りの 2 分より先まで広げる(アプリの変更で、コアではない)

## 5. 雨の作り方(SPEC 4.2)

- パッケージ `RainEffect`。`layer: .glass`、`.backdrop`、天気のヒントは曇り寄り。パラメータは雨の強さ、粒の大きさ、屈折の強さ
- 粒の計算は CPU で行う。数千個までの配列と、近くの粒を探す一様な格子。粒は場所(デスクトップの座標)、質量、速さ、付着のしきい値を持つ。決まった刻みで進め、粒の ID の順に処理して、同じ種なら同じ結果にする
- 付着のしきい値を超えると滑り出す。重力、弱い共有の風、場所でなめらかに変わる付着で、軌跡が曲がる。小粒を残しながら落ち、途中の粒を吸って速くなる
- 凪に入るたびに、その時の深まりに見合う粒の並びから始める。深い場面の静止画とギャラリーの時刻の移動は、決まった種と初めの状態から計算し直して作る
- 描画は、粒の滑らかな和の高さとその勾配(法線)を実解像度で求め、輪郭は 1 画素でなめらかにする。背景は、粒の中心へ向けてずらし、縁ほど強く曲げる(像は反転せず、拡大されて縁で強く歪む)。乾いた画素は何も描かない
- 退場では新しい粒を足さず、現れ具合に合わせて粒を縮める
- 「視差効果を減らす」と、全体の強さを下げた設定に従う

## 6. 作者に決めてもらうこと

- 決めたこと(2026-11-20): 雨の既定はオフ、ランダムモードは M2 に含める、深まりに上限を設けない
- 段階 A のあと: 予算を超えたときの扱い、取り込みの頻度(60 Hz か 30 Hz か)
- 区切り F: 粒の大きさ、拡大の強さ、光り方
- 区切り G: 本降りで覆う面積(案は画面の 12 %)

## 7. 2 つの案の突き合わせ

骨組みは両案で同じだった。取り込みはコアのサービスにし、粒の計算は CPU で行い、`nagi-render` の背景画像を取り込みの代わりに使う。深まりに合わせて粒を増やし、退場では現れ具合に合わせて縮める。

| 採った点 | 案 | 理由 |
|---|---|---|
| コアを先に仕上げて固め、雨はパッケージとして足す。完了の条件は差分で示す | Codex | 「コアに手を入れない」を示せるのはこの順だけ |
| 雨の描き方の前に負荷を測る段を置く | アドバイザー | 木漏れ日だけで 60 fps の余裕がほとんど無い。描き方は数字で選ぶ |
| 雨の既定をオフにし、設定を移行する | Codex | 今の設定では雨を足した時点でオンになり、許可のダイアログが出る(コードで確かめた) |
| 天気のヒントを、動いているエフェクトから求める | Codex | 今は起動時に合計している |
| 取り込みの開始に番号を付ける、ディスプレイの抜き差しで作り直す | Codex | 止めた取り込みが遅れたフレームで生き返らないため |
| 許可の状態を 4 つにし、許可を求めた直後の返事を当てにしない | Codex | 許可の結果がすぐには分からない |
| 許可がないときのメニューの 1 行はコアが出す | アドバイザー | 許可はエフェクトではなくコアの関心事 |
| 背景が届くまで雨は何も描かない | Claude | コアに雨のための分岐が要らない |
| 取り込みは 60 Hz から始め、30 Hz と比べる | Codex(Claude は 30 Hz から始める案) | 数字と作者の目で決める |
| 粒のあるタイルだけを塗る描き方 | Codex(候補として残す) | 全画面の高さ場と比べ、3 章の測定で選ぶ |
